# Clearline demos: how to start a session

## Where briefs live

Plans made in a normal chat never reach coding sessions on their own.
The brief must be saved to Notion: AI Agency HQ > Approved Plans, titled
"Brief, <date>".

At the start of any session, before anything else:
1. Search Notion for the newest page in Approved Plans.
2. Read it and do every item in it.
3. If no brief is there, ask for it in one short message. Do not guess.

## Ending a planning chat

The last message in a planning chat should be:
"Save this as a brief in Notion, Approved Plans."

## Rules

- Never touch Lovable.
- Push to the branch the session names. Do not open a PR unless asked.
- Keep replies short and plain.
